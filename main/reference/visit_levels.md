# Get visit or period levels from longitudinal data

Get visit or period levels from longitudinal data

## Usage

``` r
visit_levels(data, vars)
```

## Arguments

- data:

  A longitudinal data frame.

- vars:

  An `ivars` object created by
  [`set_vars()`](https://openpharma.github.io/rbmi/reference/set_vars.md).

## Value

A character vector containing the applicable visit or period levels.
